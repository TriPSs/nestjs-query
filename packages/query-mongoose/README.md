# `@ptc-org/nestjs-query-mongoose`

The `query-mongoose` package provides an implementation of the `@ptc-org/nestjs-query-core` `QueryService`, built on [NestJS](https://nestjs.com/) and [Mongoose](https://mongoosejs.com/).
