# `@ptc-org/nestjs-query-sequelize`

The `query-sequelize` package provides an implementation of the `@ptc-org/nestjs-query-core` `QueryService`, built on [NestJS](https://nestjs.com/) and [Sequelize](https://sequelize.org/).
