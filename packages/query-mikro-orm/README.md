# `@ptc-org/nestjs-query-mikro-orm`

The MikroORM persistence adapter for Nestjs-Query. It provides an implementation of the `@ptc-org/nestjs-query-core` `QueryService` for applications using [MikroORM](https://mikro-orm.io/).

## Installation

[Install Guide](https://nestjs-query.mintlify.site/introduction/install)

## Getting Started

See the [MikroORM package documentation](https://github.com/TriPSs/nestjs-query/tree/master/packages/query-mikro-orm) and the [Nestjs-Query documentation](https://nestjs-query.mintlify.site/introduction/getting-started) for setup information.
